# OpenLakeForge documentation

OpenLakeForge is an open-source lakehouse you run entirely in your own
infrastructure, small enough for one data team to operate.
These pages show how to install it, build data products on it, and deploy it
to AWS or Azure.

New to OpenLakeForge? Read the [Introduction](get-started/introduction.md),
run the [Quickstart](get-started/quickstart.md), then follow the
[Tutorial](tutorial/01-tour-the-platform.md) from lesson 1.

| Learn the vocabulary | [Concepts](get-started/concepts.md) |
| Build my first data product | [Tutorial](tutorial/01-tour-the-platform.md) |
| Add sources, domains and products | [Build and manage data products](guides/data-products.md) |
